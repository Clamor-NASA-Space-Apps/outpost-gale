# Unity Shader Graph 17.0 manual, Triplanar Node
URL: https://docs.unity3d.com/Packages/com.unity.shadergraph@17.0/manual/Triplanar-Node.html
Fetched: 2026-11-12 (WebFetch; quotes as returned)

> "Samples the input Texture 3 times, once in each of the world x, y, and z axes."
> "Blend controls the way the normal affects the blending of each plane sample and should be greater than or equal to 0."
> "A Blend of 0 makes each plane get equal weight regardless of normal orientation."
> Useful "where hand authoring UV coordinates would either be problematic or not performant."
