# Excerpts: Game Mode triggers (saved 14 Nov 2026; Apple forum pages render with JS, so excerpts from search results)
- https://developer.apple.com/forums/thread/739387 "Activate Game Mode for my App in Sonoma?": the Supports Game Mode property (GCSupportsGameMode) should be set to true, and the app's category identified with LSApplicationCategoryType. (reported)
- https://developer.apple.com/forums/thread/755799: Game Mode cannot be triggered programmatically. (reported)
- https://developer.apple.com/forums/thread/836878 (2026): a full-screen card game with the games category and GCSupportsGameMode=true never engaged Game Mode on macOS 26.5. (reported)
- LSSupportsGameMode is described as a newer key for macOS 26 and later. (reported, not confirmed in Apple docs)
- eclecticlight.co 2023-11-16 (saved: eclecticlight_game_mode_2023-11-16.html): "If that's one of the many Game categories, then macOS will automatically put that app into Game Mode when it's set to Full Screen mode."
